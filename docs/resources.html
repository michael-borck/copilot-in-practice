Microsoft’s own training

Draft, analyze, and present with Microsoft Copilot (MS-4018) is Microsoft’s free seven-module path, updated October 2026. Start with module 1, about 22 minutes. It covers the same ground as Session 2 in Microsoft’s language: Work IQ grounding, data protection, and a four-element prompt framework. Finish it for the badge if you want a record.

On this site

Companion masterclasses

These materials borrow the visual language and some of the framing from two Curtin Executive Education masterclasses by Michael Borck:

  • The Human Edge: using and delivering AI with judgement.
  • AI in Strategy: choosing where to invest.

Another Curtin course

AI literacy for Teaching Support is a two-hour Curtin course for Teaching Support Officers. It has a larger prompt playbook, more on prompt chaining, and a worked Excel and Word demo. The trade-offs table and the chaining pattern on this site are adapted from it.

The repo

The source for this site is at github.com/michael-borck/copilot-in-practice. The course outline, prompt library, checklist, survey and sanitised briefs are all there. Reuse the structure if it helps your team.
