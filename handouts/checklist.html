Copilot in Practice · Take-home checklist

Keep this visible for the first week.

One page. Tick what you have done. The habit matters more than the tool.

This week

  • Note your Copilot label: Chat (Basic), M365 Copilot (Basic) or Premium.
  • Run the context check once: ask Copilot in Outlook and Copilot Chat the same question.
  • Pick two or three tasks from your own week.
  • For each task, write the first RTCF prompt you will use: role, task, context, format.
  • For each task, name the checkpoint you will not skip.

Before you paste anything

  • Is this the approved tool? Copilot is the official tool. Claude needs access granted. Public tools are for mock data only.
  • Is this client or participant personal information? If yes, is there a reason and is it within policy?
  • Does it contain pricing, margins, contract terms or a confidentiality clause?
  • Is it third-party material the client has not cleared for this use?
  • Would I put this in a Curtin system?

If any answer is unsure, use the sanitised version or ask first.

Before you send anything

  • Right client, right program, right people?
  • Every number traceable?
  • No invented commitment, date or claim?
  • Tone right for this reader?
  • A person has read it end to end and owns it?

The carry pattern

Gather where the context lives. Extract what matters. Carry it across yourself. Refine in the destination. Check before it moves on.

Prompt, process, protect

Work out the prompt on safe material. Move the pattern into the approved tool and the real workflow. Keep sensitive work behind the human checkpoints.

The one idea

You are the orchestrator. Copilot drafts. You decide what it sees, what it keeps, and what goes out.
