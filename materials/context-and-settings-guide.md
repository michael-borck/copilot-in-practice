# Context and settings guide

A short guide for the Executive Education team. Keep it next to you for the first week.

## The thing to understand first

Copilot answers from what it can see. What it can see depends on three things: the app you are in, the licence you have, and how Curtin has configured the tenant.

Two people can be on the same licence and still get different buttons, because the tenant settings decide which features are switched on. So the useful skill is not memorising the product. It is checking your own setup, and checking again after an update.

## What each place can see

| Where you are | What Copilot usually sees |
|---|---|
| Copilot in Outlook, with an email selected | The open email, and with an add-on licence, your mailbox, calendar and related files |
| Copilot in Outlook, nothing selected | The mailbox and calendar, to the extent your licence and tenant allow |
| Copilot in Word | The open document, and files you point it to with a licence |
| Copilot in Excel | The open workbook, and the range or table you select |
| Copilot in PowerPoint | The open deck |
| Copilot Chat in the browser or Edge | The web, the page you are on, and anything you paste or upload. Work data only if you have an add-on licence and the tenant allows it |
| Copilot Chat in Teams | The open chat or meeting, and with a licence, work data |

The middle column is a guide, not a promise. Microsoft changes it. Verify on your own screen.

## Check what you have

1. Sign in at `copilot.cloud.microsoft` with your Curtin account.
2. Look under your name. One of these labels appears: Copilot Chat (Basic), M365 Copilot (Basic), M365 Copilot (Premium).
3. Basic means you get web reasoning and the content you open or upload. Premium adds work data through Microsoft Graph.
4. Open the same chat inside Outlook and ask the same question. Note the difference.

Ask this question of your own setup: "What can you see about my work right now?" The answer tells you what to trust it with.

## The carry pattern

Copilot does not move work between apps for you. You do. That is fine once you make it a habit.

1. **Gather** in the app that holds the context. In Outlook, select the email. In Word, open the document. In Edge, open the page.
2. **Extract** what matters. Ask for the decisions, the dates, the asks, the numbers. Keep it short.
3. **Carry** it. Copy the result and paste it into the next app. Say where it came from.
4. **Refine** in the destination. Ask for the shape you need.
5. **Check** before it moves on. Names, figures, commitments.

Every arrow is a copy and paste by a person. That is where judgement enters, and it is why the output is still yours.

## When carrying is not practical

You can batch several steps into one prompt, as long as you accept it is still one context and one output.

```
We will do [task] in steps.
1. Summarise the brief.
2. Identify the decisions the client needs to make.
3. Draft an outline.
4. List the gaps.
Do step 1 only, then wait for me to say continue.
```

This does not join the apps. It just stops you making five separate prompts in one chat.

## Personalisation and memory

Copilot remembers context to be useful. That is helpful and also something to manage.

- Look for personalisation or memory settings in Copilot settings. The exact menu name moves, so use the search box in settings.
- Review what it has remembered. Delete anything wrong, stale or about a client.
- If you share a machine or demo account, check what is remembered before you present.
- Turning memory off is reasonable for sensitive work. You will need to supply context each time.

## Edge

- Sign in with the Curtin account, not a personal one, or you will get the consumer experience.
- Work mode and web mode are different. Check which one you are in.
- Uploading a file is a deliberate act. Confirm the file, the permissions and the audience before you attach it.
- The page you have open is context. Close anything you would not want summarised if you are sharing your screen.

## Which tools

- **Microsoft Copilot** is Curtin's official tool for work data.
- **Claude** is available through an enterprise agreement by application. If you have access, check with IT before putting client or participant data in it.
- **ChatGPT, Gemini and personal Copilot** are for personal exploration with mock or public material only.

If you are not sure whether a tool is approved, treat it as not approved until someone confirms.

## What not to paste

- Client or participant personal information, unless there is a clear reason and it is within policy.
- Pricing, margins, contract terms and anything covered by a confidentiality clause.
- Third-party material the client has not cleared for this use.
- Anything you would not put in a Curtin system.

When in doubt, use the sanitised brief, or ask before you paste.

## A five-line check before you send anything

1. Does it name the right client, program and people?
2. Is every number one I can trace?
3. Did it invent a commitment, a date or a claim?
4. Is the tone right for this reader?
5. Would I be comfortable if the client saw how this was produced?
